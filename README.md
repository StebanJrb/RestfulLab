# 🌐 RESTful API Laboratory

## 📘 Project Description
This project is a **RESTful web service built in Java**, developed as part of a software architecture or backend development laboratory.  
It demonstrates the implementation of a **REST API** using **Java**, focusing on **resource management**, **HTTP communication**, and **data persistence** through standardized endpoints.

The lab explores key REST principles — such as **statelessness**, **resource-based design**, and **HTTP method semantics** — to provide a solid foundation for modern backend systems.

---

## 🎯 Learning Objectives
- Understand the fundamentals of **RESTful architecture** and API design.  
- Implement **CRUD operations** using HTTP methods (`GET`, `POST`, `PUT`, `DELETE`).  
- Work with **JSON serialization/deserialization** for client-server communication.  
- Integrate **JPA/Hibernate** for data persistence.  
- Apply best practices in **modular, maintainable API development**.
